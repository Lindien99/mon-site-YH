# Vider le cache du navigateur Chrome

## Procédure rapide
1. Ouvre Google Chrome.
2. Appuie sur **Ctrl + Maj + Suppr** (ou **Ctrl + Shift + Delete**).
3. Dans la fenêtre qui s’ouvre, coche uniquement **Images et fichiers en cache**.
4. Choisis la période **Depuis le début** (ou celle souhaitée).
5. Clique sur **Supprimer les données**.

## Qu’est-ce qui est effacé ?
- Les fichiers temporaires enregistrés par les sites web (images, scripts, etc.).
- Le navigateur rechargera les versions les plus récentes des pages lors de la prochaine visite.

## Ce qui n’est PAS effacé
- Les mots de passe enregistrés
- L’historique de navigation
- Les cookies (tu restes connecté aux sites)
- Les paramètres de sites

## Conséquence principale
- Les sites peuvent être un peu plus lents à charger la première fois après la suppression, car tout doit être re-téléchargé.
- Aucune donnée personnelle ni connexion n’est perdue.
